# URL to QR Code Converter

A minimalist, single-page web utility that transforms URLs into scannable QR codes. Built entirely with vanilla HTML, CSS, and JavaScript, it connects to a reliable, free API to generate codes on demand without requiring any heavy framework dependencies.

### 🌟 Features
* **Instant Generation:** Converts link inputs to QR codes in real-time.
* **Fully Responsive:** Adapts cleanly to desktops, tablets, and smartphones.
* **Zero Dependencies:** Pure vanilla code requiring zero setup, installations, or build tools.

### 🛠️ Tech Stack
* HTML5
* CSS3
* JavaScript (ES6)
* [goqr.me API](https://goqr.me) for QR generation
